# 🚀 React Admin Dashboard

A modern and responsive Admin Dashboard built using React, Material UI, and various data visualization libraries.

## 🔥 Features

* 📊 Interactive Charts (Bar, Pie, Line, Geography)
* 📅 FullCalendar Integration (Add/Delete Events)
* 📋 Data Tables with Sorting & Filtering
* 🌙 Light & Dark Mode
* 👥 User Management UI
* 📱 Fully Responsive Design

---

## 🛠️ Tech Stack

* React.js
* Material UI (MUI)
* Nivo Charts
* FullCalendar
* React Router DOM
* Firebase Hosting

## ⚙️ Installation & Setup

```bash
git clone https://github.com/chayanhati/admin-dashboard.git
cd react-admin-dashboard
npm install
npm start
```

---

## 📦 Build

```bash
npm run build
```

---

## 🌐 Deployment

This project is deployed using Firebase Hosting.

```bash
firebase deploy
```
